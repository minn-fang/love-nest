AccessKey 在这里填写后只保存在当前设备的浏览器本地，不会写进本文件、也不会出现在 GitHub 上。
你和对象各自在自己的设备上各输入一次（把 Key 私下发给对方，如微信，不要发到 GitHub/群聊）。
获取方式：阿里云控制台右上角头像 → AccessKey 管理（ram.console.aliyun.com/manage/ak）。Secret 只在创建时显示一次，忘记后只能重新创建；建议创建 RAM 子账号 Key，只授权本 Bucket 读写。
使用前先到 OSS 控制台给本 Bucket 开启 CORS（来源 *，方法 GET / PUT / DELETE / POST / HEAD / OPTIONS，请求头 *，暴露头 ETag）。
云端只存一份整包快照：先「从云端下载」再修改再「上传到云端」，两人不要同时编辑互相覆盖。
「清空记录」会清掉所有学习记录重新开始。统计按自然月计算，每月 1 号自动重新累积；累计则从「在一起的日子」（2026-10-07）起一直累积。
